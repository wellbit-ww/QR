# Вопросы, на которые отвечает SOVA (шкаф SDB702NM)

Справочник для операторов, сервиса и при сдаче портала.  
**Оборудование:** только **SDB702NM** (шкаф сухого хранения).  
**Источник ответов:** руководство по эксплуатации в базе знаний (`knowledge/sdb702-nm/`).

Формулировки ниже — **примеры**. Можно задавать вопрос своими словами — система распознаёт смысл, если он есть в РЭ.

---

## Как устроены ответы

| Тип | Что это | Примеры тем |
|-----|---------|-------------|
| **Факты из РЭ** | Точные значения, таблицы, пункты — быстрый ответ | масса 90 кг, RH%, нагрузка полки, комплектация |
| **Развёрнутый ответ (RAG)** | Поиск по руководству + формулировка ответа | детальные процедуры, разбор табл. 3.2 |
| **Честный отказ** | В РЭ нет данных — система так и скажет | Wi‑Fi, бренд датчика, IP по умолчанию |

SOVA **не отвечает** по другим моделям оборудования (SDB1106NM, Wattsan и т.д.).
