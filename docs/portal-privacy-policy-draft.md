### 2. Термины

Используются термины в значениях, определённых 152-ФЗ, в том числе: **персональные данные**, **оператор**, **обработка персональных данных**, **автоматизированная обработка**, **распространение**, **предоставление**, **блокирование**, **уничтожение**, **обезличивание**, **информационная система персональных данных**.

**Портал** — веб-приложение для доступа к информации об оборудовании, интерактивному чату поддержки и направлению обращений в техподдержку.

**Пользователь** — физическое лицо, использующее Портал по учётной записи, выданной Оператором организации-покупателю оборудования.

### 3. Сфера применения

3.1. Политика применяется ко всем персональным данным, которые Оператор получает и обрабатывает при:

- входе в Портал;
- использовании чата поддержки оборудования;
- направлении обращения в техподдержку через форму Портала;
- обеспечении работоспособности и безопасности Портала.

3.2. Портал **не предназначен** для самостоятельной регистрации пользователей и **не предназначен** для обработки персональных данных несовершеннолетних без участия законных представителей.

3.3. Портал **не использует** сторонние системы веб-аналитики, рекламные трекеры и маркетинговые cookie.

### 4. Категории субъектов и персональных данных

| Категория субъектов | Какие данные обрабатываются |
|---|---|
| Пользователи с учётной записью | логин; пароль (при входе); название организации; идентификаторы доступного оборудования; данные сессии |
| Пользователи чата | текст вопросов и ответов в чате поддержки |
| Пользователи формы поддержки | ФИО; должность; телефон; email; название организации; модель оборудования; серийный номер; текст обращения; вложения (PDF, DOC) |
| Технические данные | IP-адрес; сведения о HTTP-запросах; идентификатор сессии |

Оператор **не запрашивает** через Портал паспортные данные, платёжные реквизиты, биометрию и специальные категории персональных данных.

### 5. Цели, основания и сроки обработки

Ниже перечислены фактические сценарии обработки данных в Портале.

#### 5.1. Предоставление доступа к Порталу (вход по учётной записи)

**Цель:** идентификация пользователя и предоставление доступа к материалам и функциям Портала в отношении приобретённого оборудования.

**Данные:** логин; пароль (в момент аутентификации); название организации; перечень доступного оборудования; данные сессии.

**Действия:** сбор, запись, хранение, использование, уточнение, блокирование, удаление.

**Правовое основание:** [договор с организацией-покупателем / исполнение обязательств / согласие — уточнить с юристом].

**Срок:** на период действия учётной записи и сессии пользователя. Сессия по умолчанию — до **7 суток** с момента последней активности (параметр может быть изменён администратором).

**Примечание:** учётные записи создаются администратором Оператора. Логин и пароль могут быть указаны на наклейке, размещённой на оборудовании. Пользователь обязан хранить пароль конфиденциально.

#### 5.2. Чат поддержки оборудования

**Цель:** предоставление справочной информации по эксплуатации и обслуживанию оборудования на основе документации и базы знаний Оператора.

**Данные:** текст вопросов пользователя и сформированных ответов; идентификатор оборудования; история диалога в рамках сессии (до 10 последних реплик на каждое оборудование).

**Действия:** сбор, запись, хранение, использование, удаление.

**Правовое основание:** [договор / исполнение обязательств / согласие — уточнить с юристом].

**Срок:** в пределах срока действия сессии пользователя. После завершения сессии данные чата удаляются вместе с записью сессии, если иное не предусмотрено настройками эксплуатации Портала.

**Способ обработки:** для формирования ответа текст обращения обрабатывается **локальной программной системой на сервере Оператора** (модель искусственного интеллекта, развёрнутая на инфраструктуре Оператора). Текст чата **не передаётся** сторонним облачным сервисам генеративного ИИ.

#### 5.3. Обращение в техподдержку через форму Портала

**Цель:** приём, регистрация и обработка обращения пользователя в службу технической поддержки.

**Данные:** название организации; ФИО контактного лица; должность; телефон; email; модель оборудования; серийный номер; текст обращения; вложения; логин учётной записи Портала (для идентификации обращения).

**Действия:** сбор, запись, использование, передача (предоставление), хранение, уточнение, блокирование, удаление, уничтожение.

**Правовое основание:** согласие субъекта персональных данных, выраженное установкой соответствующего флажка при отправке формы.

**Срок:** до завершения рассмотрения обращения и дальнейшей переписки по существу обращения, но не дольше сроков, установленных внутренними регламентами Оператора и законодательством РФ.

**Порядок обработки:** данные формы **не сохраняются в базе данных Портала** и направляются по электронной почте на адреса службы поддержки Оператора: `info@sovtest-ate.ru`, `service@sovtest-ate.ru`. Вложения обрабатываются в оперативной памяти сервера только для передачи в письме.

#### 5.4. Обеспечение безопасности и работоспособности Портала

**Цель:** защита Портала от несанкционированного доступа, предотвращение злоупотреблений, диагностика сбоев.

**Данные:** IP-адрес; сведения о запросах к API; технические журналы сервера; служебные идентификаторы (логин — в отдельных событиях безопасности).

**Действия:** сбор, запись, хранение, использование, удаление.

**Правовое основание:** законный интерес Оператора в обеспечении безопасности информационных систем; исполнение требований законодательства.

**Срок:** [указать срок хранения логов, например 30–90 дней / 6 месяцев — уточнить у администратора].

### 6. Cookie и аналогичные технологии

6.1. Портал использует **только необходимые (технические) cookie** для поддержания сеанса авторизованного пользователя.

6.2. Используемый файл cookie:

| Название | Назначение | Срок |
|---|---|---|
| `portal.sid` | идентификатор сессии пользователя | до 7 суток с момента последней активности |

6.3. Cookie `portal.sid` является **httpOnly**, не передаётся сторонним сайтам и используется только для работы Портала.

6.4. Портал **не использует** маркетинговые, рекламные и аналитические cookie. Отдельный баннер согласия на маркетинговые cookie для Портала не требуется.

6.5. Вы можете ограничить или запретить использование cookie в настройках браузера. В этом случае вход в Портал и сохранение сессии могут работать некорректно.

### 7. Хранение и место обработки

7.1. Персональные данные обрабатываются с использованием средств автоматизации.

7.2. Данные учётных записей и сессий хранятся в базе данных PostgreSQL на инфраструктуре Оператора [или заказчика — уточнить фактическое размещение].

7.3. Пароли пользователей хранятся в виде криптографического хэша; Оператор **не хранит** пароли в открытом виде в базе данных Портала.

7.4. Обращения из формы поддержки передаются по электронной почте через корпоративный почтовый сервер Оператора.

7.5. По умолчанию Оператор **не осуществляет трансграничную передачу** персональных данных, обрабатываемых через Портал. При изменении данного порядка Политика будет обновлена.
