# Эталонные факты SDB1560NM

Источник: семейное РЭ `SATE.421411.001.00.00.00.00.00.000 РЭ`, редакция 2026, файл `Руководство SDB1560NM.pdf`.

## Модель и границы

Все значения ниже относятся только к **SDB1560NM** / **SDB1560M**. В руководстве есть таблицы с другими моделями серии SDB; их значения не применять к SDB1560M.

## Комплектация

- **4 колеса** для транспортирования и **4 регулируемые ножки** — для SDB1560M в таблице 1.2.
- **1 осушитель** в базовой поставке (семейная таблица 1.2).
