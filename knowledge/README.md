# База знаний для RAG

Сюда кладите документы по оборудованию. Информация в чат подтягивается **только из файлов** в подпапках ниже (данные из `equipment.json` в промпт попадают отдельно, но в векторную базу не пишутся).

## Структура

- Корень `knowledge/` — только подпапки по **`id` оборудования** из `data/equipment.json` (например `sdb1106-nm`, `sdb702-nm`).
- Внутри каждой подпапки — ваши **`.md`** файлы; можно делать вложенные папки (`manual/раздел-1.md`) — инжест обходит дерево целиком.

Пример:

```
knowledge/
  sdb1106-nm/
    руководство.md
    обслуживание/
      чек-лист.md
  sdb702-nm/
    заметки.md
```

Файлы, лежащие прямо в `knowledge/*.md` без подпапки оборудования, **игнорируются** (в лог инжеста выводится предупреждение).

## Форматы

Основной формат — **Markdown (`.md`)**. Дополнительно поддерживаются `.txt`, `.pdf`, `.doc`, `.docx` (как и раньше).

## Инжест

```bash
npm run ingest:knowledge
```

Нужны `POSTGRES_URL` и доступный Ollama для эмбеддингов (см. переменные в `src/rag/config.js`).

После инжеста при запросе чата для выбранного оборудования RAG ищет только чанки с соответствующим `equipment_id` — то есть только из папки `knowledge/<этот-id>/`.
