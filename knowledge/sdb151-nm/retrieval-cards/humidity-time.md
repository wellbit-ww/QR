# SDB151NM — влажность 60 %, не сушит, сколько ждать

Источник: раздел 1.1 (диапазон 0–80 RH%, выход не более 3 часов), п. 2.2.2 / табл. 3.2.

Синонимы: влажность 60 много, не сушит час, влажность не падает, сколько ждать после включения.

Факт:
- Поддержание влажности рабочего объёма: **0–80 RH%**, не выше окружающей; шаг 0,1; точность ±1 RH%.
- Выход на установленное значение с момента включения — **не более 3 часов**. Час работы сам по себе ещё не отказ. Это **не** длительность регенерации.
- Показание 60 RH% нужно сравнивать с **порогом SET**, не объявлять аварией сразу.
- Если влажность не снижается при закрытой двери — проверки п. 2.2.2 / табл. 3.2 (уплотнитель, замки, осушитель), не таймер азота Ррег.
