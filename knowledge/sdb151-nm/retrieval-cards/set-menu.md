# SDB151NM — кнопка SET и порог влажности

Источник: п. 1.1.4.3.5 РЭ. Только SDB151NM.

Синонимы: SET нажал и ничего, как в меню выставить влажность, задать порог, UP DN.

Факт: вход в меню — кнопка **SET**. Порог влажности: кнопки **UP/DN** (и ◄/► для разряда), диапазон **00.0–99.9 RH%**, подтверждение снова **SET**.

Если после SET «ничего не происходит»: сначала этот порядок SET → UP/DN → SET. Если нет индикации питания вообще — таблица 3.2 / п. 3.1.4 (сеть 220 В, кабель, предохранитель). Не выдумывать разборку кнопки SET и ремонт электроники.
